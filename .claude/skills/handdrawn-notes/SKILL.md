# 手繪筆記圖（兩種版型）

| 版型 | `--style` | 參考圖 | 預設比例 | 適合 |
|---|---|---|---|---|
| 卡片版 | `cards`（預設） | `assets/reference_parenting.jpg`（親子關係） | 1:1 | 一個觀點、250–400 字、快速分享 |
| 豐富版 | `rich` | `assets/reference_rich_threeviews.jpg`（視角與三觀） | 3:2 橫式 | 影片/長文完整筆記、5–7 段、500–800 字 |

使用者沒指定時：短內容用 cards；逐字稿、長文或說「詳細一點／像三觀那張」用 rich。生成時參考圖會一起送給模型當風格參考。

## 流程

1. **先拆內容，再畫圖**（最重要）。把來源濃縮進下面的版型槽位，每格字數要少：標題 ≤ 20 字、每條重點 ≤ 18 字、全圖總字數約 250–400 字。寫成 `content.md`（格式見下）。
2. 執行：
   ```bash
   python3 -I <skill 目錄>/scripts/make_note.py content.md out.png [--style cards|rich] [--ratio 1:1|3:2|4:3|3:4|16:9] [--no-ref]
   ```
   預設依版型（cards 1:1、rich 3:2）、附參考圖、模型 `gemini-3-pro-image-preview`（失敗退回 `gemini-2.5-flash-image`）。金鑰：Claude Code 雲端環境由代理自動注入；其他環境請設 `GEMINI_API_KEY`。若執行環境連不到 generativelanguage.googleapis.com（例如 claude.ai 網頁版沙盒），改為：照版型寫好完整的生成提示詞（風格段＋content.md）交給使用者，貼到 Gemini 或 ChatGPT 生成，並附上參考圖。
3. **用 Read 看圖驗字**：錯字、缺字、亂碼、多出無關日期/簽名就重生（最多 3 次），或把出錯那格字再縮短。
4. 用 SendUserFile 交付；要存雲端硬碟就請使用者自行存（Drive 工具無法上傳大圖）。

## 卡片版槽位（cards，4–7 格即可，不必全用）

| 槽位 | 位置 | 樣式 |
|---|---|---|
| 主標題 + 副標 | 頂部中央兩行 | 粗黑手寫字＋黃色螢光筆底線 |
| 主角插圖 | 左上 | 與主題相關的半身人物、溫暖表情 |
| 核心觀點 | 左欄長卡 | 3–5 條 ☑ 勾選清單，每條粗體小標＋一行說明 |
| A ≠ B 對比 | 中上 | 紙膠帶貼的卡片，左右兩欄中間大 ≠，各 2–3 個圓點 |
| 金句清單 | 右上 | ♥ 開頭的 3 句短句 |
| 雙向轉變 / 循環 | 正中 | 兩個角色＋弧形箭頭互指，各列「從 X → Y」×3 |
| 關鍵補充 | 右中 | 小芽圖示標題，3–4 行短句，角落山與小旗 |
| 時間軸 / 階段 | 左下 | 3 個人物由小到大＋箭頭，每階段標籤＋2 行說明 |
| 理想情境 | 右下 | 夕陽或場景插畫＋3–4 行文字 |
| 一句話總結 | 底部橫幅 | 黃色手繪框，2–3 行 |

## 豐富版槽位（rich，依內容選 6–9 個）

| 槽位 | 位置 | 樣式 |
|---|---|---|
| 主標題＋副標＋來源 | 左上 | 超大書法感黑字、紅印章、兩行副標，角落小字標 @帳號（時長） |
| 引言卡 | 頂部中央 | 名人素描頭像＋「引號金句」—人名 |
| 開場觀點 | 左上卡 | 羊皮紙小卡，2 個圓點 |
| 編號段落 一～六 | 四周 | 紫／藍毛筆色帶標題 |
| 核心循環圖 | 正中央 | 3–4 個水彩圓節點＋彩色弧形箭頭，中心核心詞 |
| 情境圖卡排 | 左中 | 3–4 格人物小卡，標籤＋（括號說明），下方 → 結論 |
| 對立對話 | 左下 | 兩人頭像＋對話泡泡，中間紅色 ≠，名牌（括號特質） |
| 比較表 | 右上 | 三列：圖示｜名稱｜說明 |
| 例子＋警示 | 右中 | 「例：」情境小圖 → 紅框 ⚠ 但如果… |
| 路標清單 | 中下 | 木頭路標，每塊 ✓ 一詞 |
| 總結清單 | 右下 | 螺旋筆記本＋鋼筆，☑ 4 條 |
| 重點便利貼 | 右下角 | 黃色便利貼一句話 |
| 因果鏈橫幅 | 最底部 | 紫色毛筆帶，A → B → C → D |

## content.md 格式

```markdown
# 主標題
## 副標題（可省略）
### 核心觀點
- 小標｜一行說明
### 對比：愛 ≠ 服從
- 愛：我在乎你、願意關心你
- 服從：你有想法、我就必須照做
### 轉變：父母 ⇄ 孩子
- 父母：保護→尊重、主導→陪伴
- 孩子：依賴→獨立、聽從→自主判斷
### 一句話總結
孩子每長大一歲……
```
`###` 後的文字會被畫成區塊標題；用【】寫版面提示（例如【正中央循環圖：A → B → C，中心寫「X」】【三列比較表】【黃色便利貼】），模型只照做、不畫出來。不要把槽位名稱（比較表、便利貼…）當標題，否則會被原字畫上去。

rich 版經驗（實測）：
- 一定要 2K（腳本對 pro 模型自動開）；1K 時小字會變亂碼。
- 每格說明 ≤ 15 字；清單 ≤ 4 條；總字數 > 800 字會開始掉字或重複。
- 驗圖重點：循環圖節點有沒有多畫或重複、編號段落有沒有漏號、表格小字是否亂碼。出錯就把那區字再縮短後重生。

## 風格要點（已寫進腳本；rich 另加水彩風景背景、毛筆色帶、印章、路標與筆記本元素）
米白手工紙底、粉彩水彩暈染（粉紅/鵝黃/淡藍/薄荷）、黑色手寫繁體中文、圓角手繪框、紙膠帶、愛心、嫩芽、星星點綴、日系溫柔插畫人物、資訊清楚不擁擠、不要英文、不要日期簽名浮水印。
