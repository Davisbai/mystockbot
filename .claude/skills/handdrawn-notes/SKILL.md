# 手繪筆記圖（多卡片資訊圖版型）

參考範本：`assets/reference_parenting.jpg`（親子關係的成熟之路）。生成時會把它當「風格參考圖」一起送給模型。

## 流程

1. **先拆內容，再畫圖**（最重要）。把來源濃縮進下面的版型槽位，每格字數要少：標題 ≤ 20 字、每條重點 ≤ 18 字、全圖總字數約 250–400 字。寫成 `content.md`（格式見下）。
2. 執行：
   ```bash
   python3 -I <skill 目錄>/scripts/make_note.py content.md out.png [--ratio 1:1|4:3|3:4|16:9] [--no-ref]
   ```
   預設 1:1、附參考圖、模型 `gemini-3-pro-image-preview`（失敗退回 `gemini-2.5-flash-image`）。金鑰：Claude Code 雲端環境由代理自動注入；其他環境請設 `GEMINI_API_KEY`。若執行環境連不到 generativelanguage.googleapis.com（例如 claude.ai 網頁版沙盒），改為：照版型寫好完整的生成提示詞（風格段＋content.md）交給使用者，貼到 Gemini 或 ChatGPT 生成，並附上參考圖。
3. **用 Read 看圖驗字**：錯字、缺字、亂碼、多出無關日期/簽名就重生（最多 3 次），或把出錯那格字再縮短。
4. 用 SendUserFile 交付；要存雲端硬碟就請使用者自行存（Drive 工具無法上傳大圖）。

## 版型槽位（依內容取用，4–7 格即可，不必全用）

| 槽位 | 位置 | 樣式 |
|---|---|---|
| 主標題 + 副標 | 頂部中央兩行 | 粗黑手寫字＋黃色螢光筆底線 |
| 主角插圖 | 左上 | 與主題相關的半身人物、溫暖表情 |
| 核心觀點 | 左欄長卡 | 3–5 條 ☑ 勾選清單，每條粗體小標＋一行說明 |
| A ≠ B 對比 | 中上 | 紙膠帶貼的卡片，左右兩欄中間大 ≠，各 2–3 個圓點 |
| 金句清單 | 右上 | ♥ 開頭的 3 句短句 |
| 雙向轉變 / 循環 | 正中 | 兩個角色＋弧形箭頭互指，各列「從 X → Y」×3 |
| 關鍵補充 | 右中 | 小芽圖示標題，3–4 行短句，角落山與小旗 |
| 時間軸 / 階段 | 左下 | 3 個人物由小到大＋箭頭，每階段標籤＋2 行說明 |
| 理想情境 | 右下 | 夕陽或場景插畫＋3–4 行文字 |
| 一句話總結 | 底部橫幅 | 黃色手繪框，2–3 行 |

## content.md 格式

```markdown
# 主標題
## 副標題（可省略）
### 核心觀點
- 小標｜一行說明
### 對比：愛 ≠ 服從
- 愛：我在乎你、願意關心你
- 服從：你有想法、我就必須照做
### 轉變：父母 ⇄ 孩子
- 父母：保護→尊重、主導→陪伴
- 孩子：依賴→獨立、聽從→自主判斷
### 一句話總結
孩子每長大一歲……
```
`###` 標題名稱即槽位，腳本會原樣轉成畫面說明；可自由新增槽位（如「階段」「理想情境」「關鍵補充」「金句」）。

## 風格要點（已寫進腳本）
米白手工紙底、粉彩水彩暈染（粉紅/鵝黃/淡藍/薄荷）、黑色手寫繁體中文、圓角手繪框、紙膠帶、愛心、嫩芽、星星點綴、日系溫柔插畫人物、資訊清楚不擁擠、不要英文、不要日期簽名浮水印。
